# LevelUp IA

React web app implementing the "LevelUp IA" mobile app design (see `../project/LevelUp IA Pantallas.dc.html` for the source design and `../project/uploads/LevelUp_IA_Spec_Pantallas_ClaudeDesign.md` for the spec).

Front-end only prototype — no backend, all data is local component state.

## Screens / routes

- `/` — Bienvenida (splash)
- `/signup` — Crea tu cuenta
- `/onboarding` — Onboarding (business type selection)
- `/dashboard` — Dashboard
- `/mundos` — Mundos (course worlds)
- `/leccion` — Lección (quiz)
- `/nova` — Chat con Nova
- `/paywall` — Plan Plus
- `/admin` — Panel institucional

## Development

```bash
npm install
npm run dev
```
